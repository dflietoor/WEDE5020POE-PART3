# House Of Dimpho – Part 3 

## Project Overview

House Of Dimpho is a beauty parlour based in Pretoria CBD, South Africa. This website provides information about the business, its services, prices, operating hours, and contact details. It also allows visitors to make enquiries and prepare contact messages.

The purpose of Part 3 is to improve the website created in Part 2 by adding JavaScript functionality, form validation, search features, SEO improvements, and deployment.

## Website Pages
The website consists of the following pages:
- **Home (index.html):** Introduces House Of Dimpho and its beauty services.
- **About Us (about.html):** Describes the business, its background, mission, vision, and values.
- **Services (services.html):** Displays available services and prices.
- **Enquiries (enquiries.html):** Allows visitors to ask questions about services and to make future bookings.
- **Contact (contact.html):** Provides contact information, a contact form, and location details.

## Technologies Used
- HTML5: used for website structure and content.
- CSS: for styling, layout, responsiveness, and transitions of the website.
- JavaScript: interactive features, DOM manipulation, search, and form validation.
- Visual Studio Code: this was used to draft and edit code.
- GitHub: version control and project hosting.

## Part 3 Features
### JavaScript Interactivity
The website includes JavaScript features to improve user experience:
- **FAQ accordion:** Visitors can expand and collapse frequently asked questions.
- **Service search:** Visitors can search for services by entering keywords.
- **Image lightbox:** Visitors can view service images in a larger display and close the display using the close button, background click, or Escape key.
- **DOM manipulation:** JavaScript updates page content and visibility in response to user actions.
- **CSS transitions:** Interactive elements include visual transitions.

### Forms and Validation
The enquiry form collects visitor details and the service they are interested in. JavaScript and HTML5 validation check that required fields are completed and that the information meets the specified requirements.

After a valid enquiry, the website displays a response with relevant service information. Availability and final prices should be confirmed with the business.

The contact form collects the visitor's name, email address, message type, and message. It validates the information and prepares an email using the visitor's default email application.

### Location and Contact Information
The contact page includes the business location at 174 Francis Baard Street, Pretoria CBD, and an embedded interactive map to help visitors find the business easily.

## Search Engine Optimisation (SEO)
The House Of Dimpho website includes the following SEO improvements:
- Unique page titles and descriptions.
- Meaningful heading structure.
- Descriptive image filenames and alternative text.
- Internal links between website pages.
- Responsive design for mobile devices.
- Image optimisation to improve loading speed.

Local SEO improvements include consistent business name, address, and contact information, as well as links to the business's social media profiles.

## Responsive Design and Accessibility

The website uses responsive CSS to support desktop, tablet, and mobile screen sizes. Images scale to fit their containers, and interactive elements include accessible labels and keyboard support where applicable.
